# Contributing

Please open an issue for a confusing passage, reader mismatch, interoperability question or proposed format change. Include a small story that demonstrates the problem, expected behavior, the runtime and its version, and the actual result. Remove personal information, private author notes, logs and credentials.

Keep ordinary stories readable and editable as standalone files. Separate current grammar from proposals and runtime-specific limits. A modular proposal must explain how existing single-file stories continue to work.

This repository publishes reviewed snapshots of the canonical specification at https://neokarma.md/spec.md. Grammar changes must agree with the canonical reader and guide; do not silently establish a competing format here. Report corrections here first so the sources and the next snapshot can be updated together.

A repository-wide license has not yet been selected. There is no contributor agreement or new license grant in this document. Please discuss substantial contributed text and its intended licensing before submitting it.
